 What I learned
- Regions & Availability Zones**: AWS spreads infrastructure across multiple physical locations for redundancy and to reduce latency for users.
- Edge locations**: Smaller AWS locations closer to end users, used to speed up content delivery.
- Core services**: EC2 (virtual servers), S3 (object storage), RDS (managed databases), Lambda (serverless compute).
- Payment models**: How AWS billing works — on-demand pricing, Free Tier limits.
- Shared Responsibility Model**: AWS secures the infrastructure; I'm responsible for securing my data and configurations.
